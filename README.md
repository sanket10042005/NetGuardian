# NetGuardian

NetGuardian is an AI-powered cloud infrastructure security and troubleshooting platform.

## Purpose

NetGuardian is designed to help monitor infrastructure, diagnose network and system problems, identify security issues, and provide safe recommendations.

## Current Status

🚧 Project under development

## Initial Version

The first version focuses on basic Linux system monitoring:

- CPU usage
- Memory usage
- Disk usage

## Future Goals

- Network diagnostics
- Security checks
- AWS infrastructure monitoring
- Terraform automation
- Docker
- CI/CD
- AI-assisted troubleshooting
- Safe infrastructure automation
